# Время намаза 2 — PWA

Статический сайт без сборки и сервера. Время намаза считается прямо в браузере, после первого открытия работает офлайн.

## Файлы
- `index.html` — всё приложение (разметка, стили, расчёт, интерфейс)
- `sw.js` — service worker: офлайн-кэш
- `manifest.webmanifest` — имя, иконки, режим «как приложение»
- `icons/` — иконки 192/512, maskable и apple-touch-icon

## Публикация
Загрузите папку целиком на любой хостинг со статикой и **HTTPS** (GitHub Pages, Netlify, Vercel, Cloudflare Pages, свой nginx). Без HTTPS service worker и установка не работают (кроме `localhost`).

Проверить локально:
```
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Установка на телефон
- iPhone (Safari): «Поделиться» → «На экран „Домой“».
- Android (Chrome): кнопка «Установить приложение» в Настройках или меню браузера.

## Обновление
После изменения файлов увеличьте `VERSION` в `sw.js` (сейчас `namaz2-v34`, следующая — `namaz2-v35`), иначе у пользователей останется старая версия из кэша.

## Расчёт
Формулы PrayTimes: угол солнца для Фаджра и Иши по выбранному методу (по умолчанию Всемирная исламская лига 18°/17°), Аср — шафиитский или ханафитский, для высоких широт — метод угловой доли ночи. Поправки в минутах настраиваются для каждого времени, чтобы совпасть с расписанием мечети.

В этой поставке исходник интерфейса — `index.html`: отдельные `app.html` и `build.py` отсутствуют, сборка не нужна. Рабочая версия находится в корне; вложенная папка `namaz-v2-pwa/` — прежняя копия, она не входит в архив релиза.


## Обновление: кот и азкары
- Кот: потягивания, умывание, блики в глазах, ласка при удержании, реакции на Enter/Пробел и интерактивное демо. Касания и перетаскивание сохранены. В скрытой вкладке активность останавливается, при уменьшении движения анимации ограничены.
- Азкары: тихий дождь с отдельным выключателем (изначально выключен), звуки повторения и два разных сигнала завершения. Синтез Web Audio работает локально; звук запускается только после действия пользователя и выключается при выходе из раздела или скрытии страницы.
- Прогресс текущего чтения сохраняется на устройстве; после завершения следующее открытие начинает новое чтение. Нет очков, серий или истории намазов.
- Настройки звука независимы от киблы. Новые подписи доступны на русском, английском и арабском.
- Шрифты Inter и Amiri поставляются локально, вместе с лицензиями OFL. После первой успешной загрузки PWA сохраняет весь необходимый интерфейс офлайн.

Для публикации нужны `index.html`, `sw.js`, `manifest.webmanifest`, папки `icons/` и `fonts/`. Сервер приложений, npm и сторонние звуковые файлы не требуются. Открывайте через HTTP на localhost или HTTPS на хостинге, чтобы работала установка PWA.

Покупка кота остаётся существующей тестовой: платёжный сервис не подключён.
